# DSA-Task3
Here are the python and C code for questions 1, 4, 5, 6, and 7.

Question 1: Circular Queue (Python)
Implemented on circular_queue.py
Implemented a Circular Queue using Python. It overcomes the memory wastage problem associated with linear queues by reusing empty spaces through circular movement of the front and rear pointers.
Question 2: Applications of Stacks
A stack is a linear data structure that follows the Last In, First Out (LIFO) principle. It is commonly used in function calls, expression evaluation, undo operations, and browser history management.

(b) Factorial:

Calculates the factorial of a given number using recursion.

Question 5: Enqueue and Dequeue (Python)
Implemented on Q5_enqueueanddequeue.py
Implemented basic queue operations using Python:

Enqueue: Adds an element to the rear of the queue.
Dequeue: Removes an element from the front of the queue.

Question 6: Sparse Matrix Using Arrays (Python)
Implemented on sparse_matrix.py
Implemented a Sparse Matrix representation using arrays in Python. The approach stores only non-zero elements together with their row and column positions, reducing memory usage compared to storing the entire matrix.
Question 7: Double Ended Queue (Deque) – C
Implemented using C on double_ended_enqueue.c
Implemented a Double Ended Queue using arrays in C. The program supports four main operations:

Front Insertion
Rear Insertion
Front Deletion
Rear Deletion

The implementation uses a circular array to efficiently manage queue elements.
